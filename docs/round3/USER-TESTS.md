# Hands-on test: 10 minutes each

Run with 3 people who have not used Guidewise. Use a fresh incognito window for each person (each visitor gets a fresh demo). Do not help unless they are stuck for more than a minute; that counts as "needed help". Write down what they say out loud.

## Say this

"This tool checks marketing posts for a coaching centre before they go out. Please think aloud. We are testing the tool, not you."

## Tasks

| # | Read this out | Done when |
| --- | --- | --- |
| 1 | Open https://guidewise-kohl.vercel.app. Check the sample post. What is the most serious problem it found? | They name a critical finding, such as "100% selection guaranteed" |
| 2 | Go back to the home page. Review the whole sample campaign. Does anything disagree between the caption and the brochure or landing page? | They point to the ₹14,999 price, the 12 January date or the EARLY10 code |
| 3 | The WhatsApp results post is already approved. The 2025 selections figure has changed from 4,200 to 4,500. Update it in the app. What happened to the approved post? | They find Facts and assets, switch to Meera, edit F-3, and say the post went back for re-approval |
| 4 | Open the API page. Create a key and check any sentence with it. | Findings appear in the playground |
