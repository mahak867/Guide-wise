# Changelog

## Round 3 — The Finish (19–21 November 2026)

- **Change impact** (improvement 1): any fact or rule change re-checks every draft that used it; approved pieces that no longer pass go back for re-approval with the reason; Impact panel; dismissal rate before and after each rule amendment on Insights.
- **API and MCP server** (improvement 2): scoped, hashed, revocable keys; `get_brief` and `check_draft` over REST and MCP (official SDK); playground; audit trail; per-key rate limit.
- **Campaign review with AI vision** (improvement 3): a campaign document can be read from a live web page by its address (main content only; private addresses refused, with tests); text the page hides from readers (white on white, display:none, zero-size) is flagged, labelled and checked; a sample landing page is served for trying it; the AI checks also read every campaign document and the text in each creative (one request per rule; code places each finding in the document that holds its quote); up to 4 campaign documents reviewed with the caption and creatives; prices, figures, dates and promo codes compared across all of them; AI vision reads stylised text and flags people shown for a consent check; sample campaign.
- **Reliability:** Gemini backup repaired (the old default model was retired for new keys; minimal thinking so it answers in seconds); a rate-limited AI provider is skipped for a short while instead of making every review wait; numbers inside codes ("EARLY10") are no longer read as figures; vision errors are recorded.
- **Usability:** the home page links straight to the three new features; the sample campaign opens from one link; facts can be edited in place (Edit fills the form and keeps the owner and holding line), so a judge can try change impact without retyping a fact; the demo starts with an approved post that cites F-3, so change impact takes two clicks, and the Impact panel scrolls into view when a change is saved.
- **Accuracy:** an offer cap ("the first 50 students") is no longer compared with the student-count fact; a "$" that OCR reads in place of "₹" is treated as a price, so prices in creatives are still compared across the campaign.
- **Trust and security:** approval re-checks the draft if the Brand Kit changed since its last check, and anything new blocks it; every review lists what was checked and what was skipped (and why), marking a partial review, with a Re-check button when the AI was unavailable; security headers and a Content-Security-Policy; a threat model with a test for each threat (`docs/THREAT_MODEL.md`); a clear message and a health check for a local setup with no database.
- **AI availability:** Groq limits each model separately, so its smaller model (gpt-oss-20b) now takes over text checks while the main one is rate-limited, before falling back to Gemini or to code checks only.
- **Demo over the judging period:** the embargoed fee in the demo would have become valid on 1 December 2026, while judging may still be going on, removing the sample's embargo finding; it now lifts on 1 March 2027, and a test runs the sample at three future dates.
- **Robustness:** a fuzz test (26 hostile inputs) now runs in CI; it found that the email pattern took quadratic time on very long words (about 1 s), now bounded (25 ms).
- **Brand Kit coverage:** six new code rules in the demo kit (30 rules in all), each with at least three flag and three pass test sentences: paid partnerships need #ad, #sponsored or "Paid partnership" (AD-PAID); offers need an end date or "T&C apply" (OFFER-1, advisory); competitor names go to the brand manager (COMP-1); "click here" and "read more" must say where they lead (LINK-2); lower-case multi-word hashtags get a CamelCase fix (TAG-1); stacked "!!" and more than 3 emoji in a social post (STY-EMOJI). An expired fact can name its successor (`meta.superseded_by`, no new column), and the finding then says "Use F-12 instead" and offers F-12's wording; F-11 now points to F-12. The planted-error score is unchanged and the new rules raise nothing on its 60 drafts.
- **Docs:** architecture, testing, known issues, roadmap, API reference, contributions.
