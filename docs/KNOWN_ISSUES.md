# Known issues and limits

Stated plainly, with where each one lives in the code.

1. **No sign-in.** Roles are switched with "Acting as" so judges can use the link directly. Roles are enforced on the server and each visitor gets a private workspace (`src/lib/db.ts:21`, `wsOf`), but a real deployment needs accounts and per-organisation row-level security.
2. **Free AI tiers.** Heavy simultaneous use can hit rate limits. Groq's smaller model (`openai/gpt-oss-20b`, its own limit) takes over first; its accuracy has not been measured separately from the main model's. If every provider is limited, the review finishes with code checks only and says so; "Re-check" brings the AI back about a minute later (`src/lib/engine/ai.ts:200`, three calls at a time).
3. **AI vision needs the AI service.** With no provider available, people in creatives are not detected and the review says so (`src/lib/engine/review.ts`, `visionError` in the stats).
4. **Logo check matches the logo file itself.** A recoloured logo is found (grey matching, then colour-edge matching) and reported as recoloured, and one stretched by up to 15% is found and reported as stretched; the stretch is measured in 2.5% steps, so under 8% is not reported. A redrawn logo (new shapes, a different lockup) or one stretched further is still reported as missing; a reviewer dismisses it with a reason (`src/lib/logo.ts`, `findLogoRgba`).
15. **Fonts are not identified.** Telling a brand typeface from a similar one in a flattened image needs a trained font classifier, and a wrong guess would be a confident false finding, so we do not claim it. The Brand Kit has no font field, so there is nothing to check against and the check is skipped. Text size is checked instead, estimated from the height of each OCR line (letters with and without ascenders and descenders are allowed for), which is an estimate for a typical typeface; text too small for OCR to read at all (under about 14px on a 1080-pixel post) is not measured (`src/lib/regions.ts`, `textPx`).
5. **OCR reads English.** Hindi text inside an image is not read reliably by OCR; AI vision usually reads it. Hindi in the caption is checked (`src/lib/image.ts:85`).
6. **Brand-name spelling** catches wrong capitals and spacing at capital letters ("Preppath", "Prep Path"), not every misspelling (`src/lib/engine/code.ts:363`).
7. **Code-only recall is 74%.** Paraphrased claims ("your seat is assured") need the AI checks; with AI on, recall is 98% on our held-out set.
8. **Our test set was written by us.** Accuracy numbers are optimistic; real drafts from marketers would be harder.
9. **Change impact re-checks with code only.** AI findings on a re-checked draft are kept from its last AI review rather than re-run, to save quota (`src/lib/impact.ts`).
10. **Pictures inside a PDF brochure are not checked.** A brochure is read as text: every code check and AI check runs on it, but images embedded in the PDF are not extracted. Upload them as creatives to check them (`src/app/api/extract/route.ts`).
11. **API rate limit is per server instance.** 30 calls a minute per key, counted in memory, so it is approximate across instances (`src/lib/apikeys.ts:31`).
12. **Penalty precedents** are cited as reported in press coverage; we have not read the orders themselves.
13. **No hands-on tests with real users yet.** At Round 2 we moved hands-on tests with students to Round 3; they had not been run when this was written. Usability rests on our own browser tests at desktop and phone sizes. The December pilot on the roadmap is where real marketers use it.
14. **The web page reader reads the HTML the server sends.** A page built entirely in JavaScript shows little text; copy its text from the browser instead. Addresses are checked before every request and redirect, but a host whose DNS answer changes between the check and the request is not re-checked (`src/lib/webpage.ts`).
